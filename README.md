## 🚀 אודות הפרויקט
**AttenGrow** (בהשראת פרויקט FocusFlow) היא מערכת מתקדמת שנועדה לעזור למשתמשים לשמור על ריכוז והתמקדות בזמן למידה, צפייה בתכנים או קריאה באינטרנט. 

הייחודיות של המערכת טמונה בצינור עיבוד נתונים מקומי ומאובטח: בזמן שהמשתמש צופה או קורא, מצלמת הרשת מנתחת את נקודות הפנים שלו בזמן אמת **באופן מקומי בדפדפן בלבד**. ציון הקשב המחושב מתרגם חזותית לצמח וירטואלי המגיב לרמת הריכוז של המשתמש (פורח כאשר יש קשב, ונעצר או עובר למצב מנוחה כאשר הקשב יורד).

---

## ✨ תכונות מרכזיות
* **מערכת משתמשים מאובטחת:** ניהול הרשמה, התחברות והתנתקות באמצעות טוקני JWT, הצפנת סיסמאות חזקה בעזרת אלגוריתם `bcrypt` (12 סבבים), ומנגנון Denylist לביטול מיידי של טוקנים בעת התנתקות או מחיקת חשבון.
* **ספריית תוכן אישית:** ניהול פריטי למידה דינמיים (קישורי YouTube, טקסטים ארוכים ומקורות רשת) המבודדים הרמטית לכל משתמש.
* **צינור פרטיות מבוסס AI (Attention Pipeline):**
  * שימוש בספריית **MediaPipe Face Mesh** לחילוץ 478 נקודות פנים מקומית.
  * הרצת מודל ONNX מותאם (`onnxruntime-web`) על חלון נע של 100 פריימים בקצב של 10 פריימים בשנייה.
  * **אפס זליגת וידאו:** צילומי הווידאו ונתוני הפנים הביומטריים אינם עוזבים את המכשיר מעולם – רק ציון מספרי בודד (Scalar Score) נשלח לשרת.
* **גיימיפיקציה של צמיחה:** אלגוריתם צד-שרת המחשב את זמני הקשב בפועל ומעדכן את מצב הצמח בצורה מבוקרת.
* **היסטוריה ואנליטיקה:** צפייה בסשנים קודמים, סקירת ציונים ממוצעים וניתוח מעמיק של התנהגות הלמידה.
* **ארכיטקטורת ענן מתקדמת:** מבוססת Google Cloud Run, מאחורי Load Balancer גלובלי עם תעודת SSL מנוהלת (HTTPS) וניהול סודות מאובטח באמצעות Google Secret Manager.

## 🏗️ ארכיטקטורת המערכת
המערכת בנויה כתשתית מבוזרת ומאובטחת בענן של Google Cloud (GCP):
1. **שער כניסה (Load Balancer):** התעבורה מהאינטרנט מגיעה לכתובת IP סטטית דרך HTTPS (פורט 443).
2. **ניתוב נתיבים (URL Map):**
   - בקשות ל-`/api/*` ו-`/health` מנותבות אוטומטית לשירות השרת (`attengrow-server` בפורט 8000).
   - שאר התעבורה מנותבת לשירות הלקוח (`attengrow-client` בפורט 3000).
3. **בידוד שירותים (Ingress):** שירותי ה-Cloud Run חסומים גישה ישירה מהאינטרנט ומקבלים תעבורה אך ורק דרך ה-Load Balancer.
4. **מסד נתונים חיצוני:** נתונים נשמרים במסד MongoDB Atlas מנוהל (שכבת Free Tier M0).

## 🛠️ טכנולוגיות ומבנה טכנולוגי
* **צד לקוח (Frontend):** React 18, TypeScript, Vite, MediaPipe Tasks Vision, `onnxruntime-web` (WebAssembly).
* **צד שרת (Backend):** Python 3.12, FastAPI, Motor (דרייבר אסינכרוני ל-MongoDB), Uvicorn.
* **מסד נתונים:** MongoDB Atlas (NoSQL).
* **תשתיות DevOps וענן:** Docker, Docker Compose, Google Cloud Run, GCP Load Balancer, Google Secret Manager.

## ⚙️ הרצה מקומית באמצעות Docker
כדי להריץ את המערכת המלאה בסביבה מקומית לצורכי פיתוח ובדיקה:

1. שכפלו את מאגר הקוד (Repository):
   ```bash
   git clone https://github.com/ShaniOlshtein/AttenGrow.git
   cd AttenGrow
   ```
2. הגדירו את קובץ משתני הסביבה המקומי (העתיקו את קובץ התבנית):
   ```bash
   cp env.example .env
   ```
3. הפעילו את המערכת בעזרת Docker Compose:
   ```bash
   docker compose up --build
   ```
4. גישה לשירותים:
   * **צד לקוח (Frontend):** `http://localhost:3000`
   * **בדיקת תקינות שרת (Health Check):** `http://localhost:8000/health`
